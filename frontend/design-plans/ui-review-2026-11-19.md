# UI audit and implementation — 19 November 2026

## Design language
Existing frontend DESIGN.md established slate surfaces, emerald actions, dense readable financial data, tabular figures and accessible primitives. Preserve these decisions. Audit scope: live App header/overview, shared export/order/search dialogs, broker panel and existing ComponentCanvas. Existing unrelated working-tree edits were preserved.

## Findings
| # | Problem | Evidence | Proposed change | Scope | Confidence |
|---|---|---|---|---|---|
| 1 | Navigation and overview actions exceeded available mobile width | App shared header and action row; initial 390px browser check measured document width 414px | Wrap control groups; contain navigation scrolling | App.tsx | High |
| 2 | Dialogs lacked native focus containment; dataset choices were click-only | ExportModal, OrderAllocationModal and App search overlay used div wrappers; dataset choices rendered clickable divs | Shared native dialog, explicit labels, native selection buttons and announced errors | ModalSurface and three consumers | High |
| 3 | Broker setup competed with overview hierarchy | UpstoxBrokerPanel displayed an always-expanded credentials form with a competing cyan border | Slate boundary, collapsible setup, meaningful pending/empty text | Shared broker panel | High |

## Improve first
Responsive header/actions and modal keyboard access. Both are implemented. Further changes include reduced-motion defaults, quiet loading feedback, focus styles, private dashboard metadata and a local SVG favicon.

## Validation
- TypeScript and Vite production builds passed.
- Browser: 390x844 mobile viewport fits without page-wide overflow (document width 375px excluding scrollbar); navigation has its own scrolling region.
- Export native dialog fits mobile width; eight selection controls expose pressed state. Escape closes and returns focus to Export.
- Search dialog focuses its named input and closes with Escape.
- Canvas mounts at ?canvas in development only; synthetic KPI preview, source registry, move handles, fit/reset and zoom controls. Keyboard movement and saved positions survived reload. Console error check returned no entries during these checks.
- DESIGN.md CLI 0.4.0: lint reports zero errors, one missing-primary warning; retained established palette names instead of inventing a semantic alias. css-tailwind exports all five colors. No custom typography, radius, spacing or component token scales were inferred. Prior/current document diff reviewed.

## Limits and follow-up
This is a targeted UI pass, not a full accessibility certification or backend/data audit. Canvas touch pinch, nested trackpad-scroll routing, space pan from focused preview controls, portal focus reveal and real browser history-swipe behavior are not fully implemented or validated. Do not treat the canvas as a complete gesture editor. No supported alternate product theme exists, so no theme selector was invented. No real order or allocation was submitted.
