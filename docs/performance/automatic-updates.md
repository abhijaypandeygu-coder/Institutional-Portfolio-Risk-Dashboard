# Automatic chart updates

Overview now automatically refreshes benchmark history, recorded performance/history/events, current NAV reads, market-watch quotes and holdings sparklines. Market requests run 30 seconds after the previous request completes. Holdings refresh every 120 seconds because the existing liquidity aggregation is more expensive. This does not execute valuations, create historical snapshots, generate reports, place orders, or start broker subscriptions.

The shared Auto refresh checkbox pauses scheduled requests. Refresh now requests a new check across mounted resources, including while automatic refresh is paused. Requests do not overlap within a resource. Hidden tabs and offline browsers suspend scheduled work; returning to a visible online tab resumes it. Unmounting or changing scope aborts old requests. Requests have a 45-second cancellation timeout. Failed refreshes preserve the last successful data and retry with bounded backoff (up to 120 seconds).

Yahoo history caches now expire after 30 seconds. Provider-retrieved time and latest bar timestamp remain distinct from the frontend last-check time. Updating a daily or 15-minute bar is not a tick stream. Markets that are closed may return identical prices across refreshes. Yahoo data may be delayed. Upstox remains a separate, authenticated broker integration with its existing explicit subscriptions and monitoring controls; this change does not route US portfolio symbols through Upstox.

Recorded NAV and TWR/MWR analytics change only when new authoritative records exist. No artificial points are appended to make a chart appear active. Existing event, report, cash-flow, and excess-return availability rules remain in force.
